# KNSO Planning Study Documentation

This documentation contains the background information, assumptions, system data, planning requirements, methodologies, and engineering decisions supporting the Power System Planning Engineering Lab.

The planning study follows the fictional Republic of Kanyisa and the Kanyisa National System Operator (KNSO).

The documentation should be treated as the official planning record for the study and is intended to provide sufficient context for all modelling decisions undertaken throughout the engineering laboratory.

## Documentation Structure

### 01 Kanyisa Background

Background information describing the Republic of Kanyisa, its electricity sector, geography, and planning institutions.

### 02 System Data

Technical information relating to the generation fleet, demand forecasts, fuel supplies, renewable resources, and transmission system.

### 03 Policy and Constraints

Planning directives, reliability standards, emissions targets, and other system requirements.

### 04 Study Guides

Documentation supporting each planning study undertaken in the laboratory.

### 05 Methodology

Descriptions of modelling approaches and analytical techniques used throughout the project.

### 06 Engineering Decisions

A record of significant engineering and modelling decisions made during the project.

### 07 Glossary

Definitions of planning, reliability, and energy system modelling terminology.
